# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome!

Thank you for taking the time to contribute to this project. Your support helps make this tool better for everyone.

---

## How Can You Contribute?

### 1. Reporting Bugs
If you find a bug or error while using the project:
* Open an **Issue** on GitHub.
* Clearly describe the problem, including steps to reproduce it.
* Include details about your environment (e.g., Python version, OS).

### 2. Suggesting Enhancements & Ideas
If you have an idea for a new feature or improvement:
* Open a new **Issue** with the tag `enhancement`.
* Explain the rationale behind your idea and how it improves the project.

### 3. Submitting Bug Fixes & Code Contributions
To submit code or documentation updates:
1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/<your-repo-name>.git
