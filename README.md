# Simple Interest Calculator

A simple, user-friendly script/application designed to compute simple interest based on principal amount, annual interest rate, and time period in years.

## Formula Used

The simple interest is calculated using the standard formula:

$$A = P \cdot (1 + rt)$$

Where:
- **P** = Principal amount
- **r** = Annual interest rate (in decimal, e.g., 5% = 0.05)
- **t** = Time period (in years)
- **A** = Total amount (Principal + Simple Interest)

---

## Input Variables

| Parameter | Description | Unit |
| :--- | :--- | :--- |
| **Principal ($P$)** | The initial amount of money invested or borrowed | Currency (e.g., USD, INR) |
| **Rate ($r$)** | The annual interest rate | Percentage (%) per year |
| **Time ($t$)** | The duration of investment or loan | Years |
