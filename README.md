# Paradise Nursery Shopping Application

Paradise Nursery is a dynamic React-based e-commerce web application designed for plant enthusiasts. The application allows users to explore a diverse collection of houseplants, view detailed product information, manage their shopping cart in real-time using Redux state management, and calculate total purchase costs seamlessly.

---

## Features Overview

- **Landing Page:** Interactive homepage featuring company background, mission statement, and a "Get Started" call-to-action button.
- **Product Categorization:** Houseplants categorized into distinct groups (e.g., Air Purifying, Aromatic, Low Maintenance), featuring at least six unique plants per category with thumbnails, names, and prices.
- **Dynamic Shopping Cart:**
  - Add items to cart with automatic button state updates (disabled once added).
  - Real-time updating of total item count in the navigation bar.
  - Increment and decrement item quantities or remove items entirely.
  - Dynamic total price calculation per item and for the entire cart.
- **Seamless Navigation:** Shared responsive navigation bar allowing quick transitions between Home, Product Listing, and Cart views.
- **Checkout Flow:** Interactive checkout feature displaying placeholder alerts for upcoming payment integrations.

---

## Tech Stack

- **Frontend:** React.js, JSX, CSS3
- **State Management:** Redux Toolkit (`@reduxjs/toolkit`), React-Redux
- **Build Tool:** Vite / Create React App
